One font, one size, one leading.

Every first baseline sits at the same offset inside its own line box.

So a page like this has a single phase, and a single origin serves it.

Move the origin and every line moves together.

That is the one-line-fix case, and it has to be distinguishable from the other one, because in a screenshot they look identical.

Scattered drift means the type scale and the spacing scale disagree.
